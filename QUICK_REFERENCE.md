# Quick Reference

## Wording

`Create a new animation`

- Create a new file.

`I want a new animation file`

- Create a new file.

`Add to my file`

- Edit the existing file.
- Update the current `Scene` class or helper function.

`Add another animation to this file`

- Create a new file instead.

`Modify`, `update`, or `change`

- Edit existing code.
- Do not create a new file.

## Examples

`Create a new animation about binary numbers`

- Create `animations/binary/binary_numbers.py`

`Add another animation to fetch_decode_execute_story.py`

- Create a new animation file instead of adding a second `Scene` class

`Add a helper function to my floating point file`

- Edit `floating_point_story.py`
- Add a helper function

## Run Commands

```bash
python animations/fetch_decode_execute_story.py
python animations/toaster_black_box.py
```

## VS Code

- Run button on an animation file -> runs that file directly
- `Ctrl+Shift+B` -> run the current file
